# 16: Decide the story premise

**What to build:** A written decision on the story premise (drama about the people, or about the world and why it is the way it is), made before M3 content is built because it shapes the first gate's tone.

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [ ] Premise written in a few sentences, with the mystery or hook that makes it original
- [ ] Tone for the first gate and the System's voice noted

## Comments

**2026-11-13 (developer, recorded by agent):** Partly decided; both boxes stay open.

Decided:
- **Focus:** a world mystery carried by a small fixed cast. The spine is why the world has gates and a System at all; the NPC cast gives it people to care about and works for any party size.
- **First gate's tone:** uneasy and small. The player is weak and it shows: a cramped, quiet place where something is slightly wrong, so the climb starts from real vulnerability.
- **The System's lines:** the developer will write them. No voice has been chosen yet.

Not decided:
- **The hook.** The developer is not sure yet, and is now thinking about a fantasy setting. That would change the framing of hunters, gates, ranks and the System from the modern-day default of the genre.
- **The System's voice.** To be noted once the developer has written some lines.

Hooks offered and not chosen (kept in case one is useful later):
- *The System is a ledger:* gates are debts being collected, and each level is credit.
- *Gates are memories:* each gate replays a world that already ended, and the System is its archive.
- *The System is hiring:* ranks are an interview, and A-rank hunters stop coming home.

To close this ticket before M3 (19, 20):
1. Settle the setting: fantasy or not.
2. Write the premise in a few sentences, with its hook.
3. Note the System's voice, for example with three or four sample lines.

**2026-11-13 (developer, recorded by agent):** Setting decided: fantasy.
- **Hunters** are an adventuring guild whose purpose is to go into dungeons and clear them out.
- **Everyone has a System.** It is an ordinary part of life in this world, not something that singles out the player.
- **Rank is a licence** issued for guild work. At the higher ranks it can also be used as a title.

Follows from this, to settle with the premise:
- **The hook is still open.** With a System everyone has, the mystery cannot simply be "why do I have one". It has to be something about the dungeons, the guild, or what the System is.
- **Words:** the spec and code say "gate" for a run; the developer said "dungeon". Decide whether a gate is the entrance to a dungeon or whether "dungeon" replaces "gate" in the player-facing text. No code needs to change either way.
- **Promotions** (spec story 9, "authored story events") become the guild granting a higher licence.
