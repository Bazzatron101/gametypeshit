# 19: Hub

**What to build:** A small, shared, host-owned hub where players gather, pick a gate from the gate board, enter it, and return. The hub doubles as the lobby.

**Blocked by:** 13: Two-player Steam co-op, 17: Gate runtime

**Status:** ready-for-agent

- [ ] Players can walk around a small hub together
- [ ] A gate board lists available gates and starts one for the party
- [ ] Returning from a gate puts the party back in the hub
- [ ] The hub holds several players without breaking, with the ten-bot test used to check scale
